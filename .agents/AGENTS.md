# Git 자동화 및 다국어 지원 규칙

이 프로젝트에서는 작업 완료 시 항상 최신 상태를 유지하고 변경사항을 안전하게 커밋 및 푸시하기 위해 아래의 Git 작업을 자동화합니다.

## Git 작업 완료 규칙 (Git Automation)

1. **커밋 메시지 한글화 (Korean Commit Message)**:
   - 구현한 내용의 요약을 명확히 작성하되, **반드시 한국어(한글)**로 커밋 메시지를 작성해야 합니다.
   - 예시: `feat: 마우스 움직임 반응형 배경 컴포넌트 추가 및 전역 레이아웃 적용`

2. **자동 동기화 프로세스 (Pull, Add, Commit, Push)**:
   - 각 작업 단계(기능 구현 등)가 완료되고 정상 동작을 확인한 즉시, 별도의 요청이 없더라도 자동으로 다음 Git 명령을 순차적으로 제안 및 실행해야 합니다:
     1. `git pull` (원격 브랜치 변경사항 충돌 방지)
     2. `git add .` (또는 변경된 특정 파일)
     3. 한글 메시지로 `git commit -m "..."` 실행
     4. `git push` 실행
